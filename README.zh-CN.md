# zotfile-lite

[English](README.md) | 简体中文

适用于 Zotero 7–10 的附件管理插件：根据条目的元数据（作者、年份、标题等）自动重命名附件，并可把附件移动到指定文件夹、按规则建立子文件夹。

## 安装方法

1. 在本仓库的 [Releases](https://github.com/el0808/zotfile-lite/releases) 页面下载最新的 `zotfile-lite.xpi`。
2. 打开 Zotero，选择菜单 **工具 → 插件**。
3. 点击右上角的齿轮图标，选择 **从文件安装插件…**，选中下载的 `zotfile-lite.xpi`。
4. 安装后无需重启。在任意条目上点击右键，出现 **zotfile-lite** 子菜单即表示安装成功。

> 如果之前装过本插件的旧版本（显示名为 “ZotFile for Zotero 10” 或 “zotero-lite”），请先在插件列表中将其删除，再安装新版本。原有设置会保留。

## 使用指南

### 第一步：打开设置

通过以下任一方式打开设置页：

- **编辑 → 设置**，在左侧选择 **zotfile-lite**；
- 在条目上点击右键，选择 **zotfile-lite → zotfile-lite 首选项…**。

### 设置文件名格式

在 **重命名规则 → 文件名格式** 中填写规则，默认是：

```
{%a_}{%y_}{%t}
```

生成的文件名形如 `Vaswani_2023_Attention Is All You Need.pdf`。

先在主窗口选中一个条目，再切回设置窗口，下方的 **预览** 会显示该条目按当前规则生成的文件名。修改规则或任何选项时，预览会立即更新。

#### 常用通配符

| 通配符 | 含义 |
| --- | --- |
| `%a` | 作者姓氏（多位作者用 `_` 连接） |
| `%A` | 第一作者姓氏的首字母 |
| `%F` | 作者姓氏 + 名的首字母，如 `VaswaniA` |
| `%I` | 作者姓名首字母，如 `AV` |
| `%g` | 作者全名，如 `Vaswani, Ashish` |
| `%q` | 最后一位作者的姓氏 |
| `%d` | 编者姓氏 |
| `%y` | 年份 |
| `%t` | 标题（可按下方选项截断） |
| `%h` | 短标题 |
| `%j` | 期刊名 |
| `%s` | 期刊缩写 |
| `%p` | 出版社 |
| `%w` | 按条目类型取出版方：期刊文章取期刊名，学位论文取学校，报告取机构，其余取出版社 |
| `%v` / `%e` / `%f` | 卷 / 期 / 页码 |
| `%T` | 条目类型 |
| `%c` | 条目所在的分类路径 |
| `%b` | Better BibTeX 引用键（需安装 Better BibTeX） |

#### 规则语法

- **花括号 `{…}`**：括号里的内容只有在其中所有通配符都有值时才会出现。例如 `{%a_}{%y_}{%t}` 中，条目没有年份时，`_` 也不会多出来。
- **竖线 `|`**：取第一个有值的通配符。例如 `%a|%d` 表示有作者用作者，没有作者时用编者。

#### 文件名选项

| 选项 | 效果 |
| --- | --- |
| 截断过长标题（在 . : ? ! 处截断） | 标题只保留第一个句号、冒号、问号或感叹号之前的部分 |
| 右侧数字（默认 80） | 标题的最大长度，超出部分会被截掉 |
| 在单词边界处截断标题 | 截断时不把单词从中间切开 |
| 限制作者数量 + 数字（默认 2） | 作者超过该数量时，只保留第一作者 |
| 作者被截断时追加 et al | 截断后在作者后加上 ` et al` |
| 移除句点 / 空格替换为下划线 / 转换为小写 / 移除变音符号 | 对生成的文件名做相应处理 |
| 使用 Zotero 自带的命名方案 | 忽略上面的规则，改用 Zotero 自己的文件命名设置 |

### 设置附件位置

- **在 Zotero 库中存储副本（导入附件）**：勾选时，附件保存在 Zotero 自己的存储目录中，只做重命名。
- 不勾选时，附件会被移动到 **链接附件的目标文件夹**，在 Zotero 中以链接文件的形式保存。点击 **选择…** 可以选择文件夹。
- **创建子文件夹**：在目标文件夹下按规则建立子文件夹。规则使用同样的通配符，用 `/` 分隔层级。例如 `/%w/%y` 会把文件放到 `目标文件夹\期刊名\年份\` 下。此选项只对链接附件生效。

群组文库不支持链接文件，其中的附件始终以存储副本的形式重命名。

### 手动重命名附件

选中一个或多个条目（或附件），点击右键，选择 **zotfile-lite → 重命名并移动附件**。选中的条目下所有符合文件类型的附件都会按当前规则重命名，并按附件位置的设置移动。一次处理多个附件时会先弹窗确认。

完成后右下角会弹出结果窗口，点击窗口可以立即关闭。窗口停留时间可在设置的 **提示窗口** 中调整。

### 从源文件夹附加新文件

适合 “先在浏览器里下载 PDF，再挂到 Zotero 条目上” 的场景：

1. 在设置的 **源文件夹** 中选择你的下载文件夹。
2. 下载好 PDF 后，在 Zotero 中选中对应条目，点击右键，选择 **zotfile-lite → 从源文件夹附加新文件**。
3. 插件会取出源文件夹中最近修改的文件，弹窗确认后，重命名并附加到该条目上。

勾选 **附加源文件夹中的所有文件** 时，会一次附加源文件夹中的全部文件。**仅限这些文件类型** 用来限制处理哪些扩展名，默认是 `pdf,doc,docx,txt,rtf,djvu,epub`。

### 自动重命名

新附件被添加到条目上时（例如从浏览器保存文献、把 PDF 拖到条目上），插件会按 **自动重命名** 的设置处理：

| 选项 | 行为 |
| --- | --- |
| 从不自动重命名 | 不处理，只能手动重命名 |
| 总是询问 | 每次都弹窗显示 “原文件名 → 新文件名”，确认后才重命名 |
| 当条目已有其他附件时询问 | 条目只有这一个附件时直接重命名，已有其他附件时先询问 |
| 总是重命名 | 不询问，直接重命名 |

> 提示：Zotero 7 起自带附件自动重命名（**设置 → 常规 → 文件重命名**）。如果两者同时开启，文件可能先被 Zotero 改名、再被本插件改名。建议只保留其中一个。
